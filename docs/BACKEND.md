# Бэкенд: один файл задач

С ноября 2026 приложение работает на своём простом формате по образцу плагина Макса (`kudrmax/obsidian-task-tracker`). Папку `TaskNotes` и данные плагина приложение больше не читает.

## Где что лежит

В настройках выбирается папка `SuperPooperApp`. Приложение видит только её и **ничего не создаёт, если внутри нет `Task Manager`**: так случайно выбранная папка остаётся нетронутой.

```
SuperPooperApp/
  super-pooper-app-settings.json     настройки приложения
  Task Manager/
    Tasks.md                         все открытые задачи
    Done.md                          выполненные задачи и дни привычек
    Habits settings/
      a1b2c3d4.json                  настройки одной привычки
      Trash/                         удалённые привычки
```

Имена, заголовки разделов, галочки и значки — в `Resources/Config/task-file.json`, в коде их нет.

## Tasks.md

```markdown
%% format 2 %%
%% day 2026-11-04 %%

## Next actions
- [ ] 🚿 Холодный душ 📅 2026-11-04 🌅 morning 🔁 every-day 🆔 a9fc7aff
- [ ] Побриться #in_today_pool
- [/] Написать отчёт 📅 2026-11-04 ⏰ 14:00 🎵 chime ⏳ 60 ⚠️ 🐸
    Текст задачи — строки с отступом.
    - [ ] Подзадача
- [ ] Отменить Sigma 📅 2026-11-02 ⚠️ 🕰️ #in_today_pool #section_morning
- [ ] 🏋️ Зал 📅 2026-11-09 🕐 19:00 🔁 every-mon-sat 🆔 2e47c3dc
## Soon
- [ ] Записаться к стоматологу 📅 2026-11-20
## Someday
- [ ] Поездка к Маше 🗂️
    - [ ] Купить подарок
## Archive
## Trash
- [ ] Старое 🗑️ 2026-11-02
```

```markdown
## Done
- [x] Вазелин ✅ 2026-11-03
- [x] 🏋️ Отжимания ✅ 2026-11-03 🆔 2e47c3dc
```

Второй блок — это `Done.md`.

- **Раздел = горизонт (формат 3, D-175).** `## Next actions` — ближайшее, `## Soon` — примерно месяц, `## Someday` — дальнее. Раздела `## Today` и групп `### Morning` / `### Day` в файле нет. Перенос в приложении переносит строку, перенос строки руками в Obsidian меняет лист.
- **Дата — это срок.** Сама по себе она дело никуда не переносит и файлом не переписывается.
- **Сегодняшний пул — метка `#in_today_pool`.** В пуле стоит только строка с ней; исключение — дело со временем на сегодня, оно на таймлайне. Метку ставит смена дня (ниже), снимает Not today. Дата на сегодня или раньше, поставленная в приложении, ставит метку, дата позже — снимает.
- **Секция пула — метка `#section_…`**: `#section_morning`, `#section_evening`, `#section_day`, своя — `#section_` и название через `_` (`#section_after_work`). Дело без метки стоит по своей рутине, а без рутины — в Day. Метка неизвестной секции создаёт в приложении свою секцию с таким названием. Порядок секций и дел в пуле хранит приложение, в файле его нет.
- **Проект — родитель с `🗂️`.** Его сабтаски стоят под ним с отступом. Он показывается на странице Lists в группе Projects; сам в пул не идёт. Своих листов (`## Lists` с `### Заголовок`) больше нет: старый файл при первом чтении переходит — `## Lists` читается как Someday, каждый `### Заголовок` становится строкой-проектом `🗂️` в Someday, его строки — её сабтасками (перед этим делается резервная копия). Любой другой `### Заголовок` тоже становится проектом (заголовки старого `## Today` до этого становятся метками секций).
- **Архив — отдельная секция.** Строка в `## Archive` сама никуда не переходит, какие бы дата и время у неё ни стояли.
- **Галочка:** `[ ]` открыта, `[/]` начата, `[x]` выполнена. Лист от этого не меняется. Начать задачу можно из контекстного меню на вкладке Tasks.
- **Время и будильник:** `🕐` перед обычным временем, `⏰` перед временем, которое звонит. Убрали будильник — снова `🕐`. Звук не по умолчанию пишется отдельно: `🎵 chime`. Нет времени — остаётся только `📅`.
- **Первая строка файла** `%% format 2 %%`: в файле без неё `⏰` значил просто время, а будильник стоял отдельно как `🚨`, поэтому при первом чтении такие строки не начинают звонить.
- **Поля — в конце строки**, каждое со своим значком: `📅` дата, `🕐` или `⏰` время, `🌐` часовой пояс (обычно пусто), `⏳` длительность в минутах (`default`, id звука из `rules.json` → `alarms`, `sys-…` тон телефона, `custom-…` свой звук), `⚠️` high priority, `❤️` приятно, `🐸` требует энергии, `🌅` рутина, `🔼` родитель (если подзадача лежит в другом разделе), `🪜` показывать сабтаски по одному (D-155), `🔁` правило повтора, `🕰️` просрочена, `#in_today_pool` в сегодняшнем пуле, `#not_tomorrow` убрано из завтрашнего пула, `#section_…` секция пула, `✅` выполнена, `🗑️` удалена, `🆔` id (только у привычек и повторяющихся задач). Значок внутри названия остаётся названием: поля читаются только с конца строки.
- **Одно свойство даты вместо `due`.** Есть просто дата и просто время.
- **Подзадачи и текст** — строки с отступом под задачей.
- **Подзадача идёт за родителем.** Строка под родителем без своей даты стоит в его дне и его разделе: дата пишется только у родителя, и при его переносе подзадача переезжает вместе с ним. Своя дата с временем или другой раздел отделяют её. Строка с `🔼` без своей даты в разделе родителя при чтении возвращается под него. Метку пула подзадача носит свою: Not today и «вернуть в пул» у родителя проходят по его открытым подзадачам, новая подзадача родителя из пула тоже в пуле.
- Всё остальное в файле (другие разделы, посторонние строки) сохраняется как есть. У обычной задачи `🆔` нет: приложение узнаёт её по самой строке. Старые `🆔` у обычных задач исчезают при первой записи.

### Смена дня

«Сегодня» везде считается по логической границе дня из настроек, а не по календарной полуночи. Строка `📅 2026-11-05 ⏰ 01:00` при границе 04:00 относится к логическому 4 ноября.

Вторая строка файла `%% day 2026-11-04 %%` (комментарий Obsidian, в просмотре не виден) говорит, за какой день файл уже приведён в порядок. Если при чтении там другой день (или строки нет), день сменился (`TaskFileStore.turnDay`):

0. Дела с `#not_tomorrow` (убранные из завтрашнего пула в разборе накануне, D-179) метку пула не получают, а сам `#not_tomorrow` снимается.
1. Со всех дел снимается `#in_today_pool`, и снимаются метки секций, кроме `#section_morning` и `#section_evening` (`task-file.json` → `pool.lastingSections`).
2. У незавершённого дела с прошедшей датой дата остаётся, а время, часовой пояс и будильник убираются: время прошло вместе с днём. Строка получает `🕰️`.
3. `#in_today_pool` ставится (`TodayPool.dayTurn`) на дела Next actions без даты и на дела из Next actions, Soon и Someday с датой сегодня или раньше. Пул состоит только из Next actions: дело из Soon или Someday при этом переезжает в `## Next actions` (подзадача — с `🔼` родителя). Не ставится: проекту `🗂️`, ждущему шагу проекта «по одному» `🪜`, делу со временем на сегодня (оно на таймлайне) и привычкам (они идут по своему правилу).
4. В строку дня пишется сегодняшний день.

Убранное вчера (Not today) сегодня снова приходит в пул и в Morning Review. `🕰️` снимается, когда задаче меняют дату или время.

**Старый файл (формат 2) с `## Today`** переходит один раз при первом чтении, перед этим делается резервная копия (`Backups/…-format3`): строки `## Today` уходят в `## Next actions` и получают `#in_today_pool`, заголовок группы становится меткой секции на её строках (`### Morning` → `#section_morning`, `### Day` — без метки). Старое приложение каждое утро ставило делам пула сегодняшнюю дату, поэтому у строки без времени дата до дня файла включительно убирается: в пуле её держит метка. Дата со временем и дата позже остаются. Остальное старое читается как раньше: `## Soon` становится `## Next actions`, `## Half year` — `## Soon`, строки из `## Waiting` и `## Now` уходят в `## Next actions`, теги `▶️` становятся `[/]`, а `⏸️` исчезают, `## Done` переезжает в `Done.md`, строки из `## Inbox` уходят в `## Soon`, `➕` исчезает при первой записи, `🔥` становится `⚠️`.

### Время

Время задачи одно: `🕐` или `⏰` в её строке. Блок на таймлайне, уведомление и будильник (`🚨`) берут его оттуда.

| Что случилось | Что в строке |
|---|---|
| Перетащили на таймлайн, поставили в выборе даты | новые `📅` и `⏰` |
| Перетащили в пул | `⏰` убран, дата та же |
| Snooze с уведомления | `⏰` = момент повтора (длительность — в настройках, по умолчанию 30 минут) |
| Not today | у задачи со временем на сегодня: то же время следующего логического дня; без времени: снимается `#in_today_pool`, дата та же |
| Логический день кончился, задача не закрыта | дата та же, `⏰`, `🌐` и `🚨` убраны, `🕰️`, `#in_today_pool`: задача в пуле |

Два исключения из «одно время»:

- **Просроченный блок в течение дня.** Время прошло, задача не закрыта: на таймлайне блок едет за линией «сейчас», а в строке остаётся своё время.
- **Привычка.** Её времена на все дни лежат в JSON (`reminderTimes`). Перенос блока или Snooze меняет только сегодня: это хранится в состоянии дня (`TimeMove`, не в vault), а в файл попадает как `⏰` на сегодняшней строке привычки. Завтра снова как в JSON. Время, поправленное в этой строке руками, при следующей синхронизации переезжает на таймлайн и в уведомление, только на сегодня; настройки привычки не меняются.

### Будильник

Время с `⏰` звонит через AlarmKit: на экране название задачи, кнопка Snooze и системный слайдер. Слайдер только останавливает звонок: задача остаётся открытой и на таймлайне, а сразу после него приходит обычное уведомление с кнопкой Done. Snooze пишет в строку время «сейчас + минуты из настроек» и ставит новый будильник. Пока будильник не остановлен, обычного уведомления рядом с ним нет. Если будильники в системе запрещены, вместо него приходит обычное уведомление со звуком.

Подпись слайдера («slide to stop») задаёт iOS: начиная с iOS 26.1 приложение не может её менять, на 26.0 там написано Done. Свои звуки добавляются в настройках, конвертируются в `.caf`, обрезаются до 30 секунд и лежат в `Library/Sounds` приложения, так что на другое устройство сами не переедут.

### Not today

Not today у задачи снимает `#in_today_pool`: дело остаётся в своём листе со своей датой и в пул не попадает до следующей смены дня. У привычки Not today ставит её строку на завтра. Если своего дня завтра по правилу нет, она завтра стоит в пуле без времени и с `🕰️`.

Новая задача без даты создаётся в `## Next actions` без метки и приходит в пул со следующей сменой дня. «+», брошенный в сегодняшний пул, ставит новой задаче метку, а не дату. «Вернуть в пул» (из разбора или со страницы листа) ставит метку и дату не трогает.

### Open in Obsidian

Открывает `Tasks.md` на строке задачи и подсвечивает её, у привычки это её открытая строка. Делает это плагин из `obsidian-plugin/`, без него ссылка файл не откроет. Файл при этом не меняется. Старая метка `^open` в конце строки при чтении не становится частью имени и исчезает при следующей записи.

### Имена

Имя занято только открытой задачей или привычкой. Строки в `Done.md` и `## Trash` имя не занимают: новая задача с тем же именем создаётся без номера. Две одинаковые открытые строки пока нельзя: приложение различает открытые задачи по имени, новая получит номер.

### Привычки и повторяющиеся задачи

Настройки — JSON-файл в `Habits settings/` (имя, правило повтора, напоминания, какие из них будильники, цвет, рутина, цель, текст…) с постоянным id. В `Tasks.md` у привычки ровно одна открытая строка, её пишет приложение:

Строка привычки всегда в `## Next actions`, наверху; меток пула у неё нет.

- **Сегодня её день и он не закрыт:** `📅` сегодня, `⏰` сегодняшнее время.
- **Иначе:** `📅` ближайший день по правилу, `⏰` первое время из настроек.

`🔁` показывает правило одним словом: `every-day`, `every-6-days`, `every-mon-sat`, `every-2-weeks-mon`, `every-15-of-month`, `every-last-day-of-month`, `every-last-sat-of-month`, `every-year-03-21`. Само правило живёт в JSON, строка только показывает его. Начала и конца у повтора нет: начало — ближайший подходящий день, конец бесконечен.

**Выполнение.** В `Done.md` появляется копия с датой без времени, а открытая строка получает следующую дату. У привычки Twice после первого выполнения строка остаётся на сегодня, после второго уходит дальше, и в `## Done` две одинаковые строки за день.

**Просрочка.** День привычки прошёл, она не закрыта:

- На новый день правило её тоже ставит: строка просто пишется заново, никакой просрочки.
- Не ставит: строка встаёт на сегодня без времени, с `🕰️`, и стоит в пуле, пока её не выполнят или не настанет следующий день по правилу.

**Имя.** Строки в `Done.md` связаны с привычкой через `🆔`. При переименовании они сохраняют старое имя, файл целиком не переписывается.

История привычки — строки в `Done.md` с `✅ дата` и `🆔` привычки:

| Отметка | В файле |
|---|---|
| Done | одна строка `[x]` |
| Partially | одна строка `[/]` |
| Twice | две строки `[x]` за один день |

Поставить галочку на сегодняшней строке привычки в Obsidian — то же, что отметить её в приложении.

Почему настройки привычек отдельными файлами, а не JSON в конце `Tasks.md`: правка привычки не трогает большой файл, поэтому меньше конфликтов в iCloud, а `Tasks.md` остаётся чистым и читаемым.

## Зеркало приложения

Строка задачи сама говорит, в пуле ли она и в какой секции; приложение пишет это при каждом изменении. После каждого изменения приложение переписывает только строки привычек (`DayMirroring.mirror`): наверху `## Next actions` строка на сегодня у каждой привычки дня, в порядке пула и таймлайна, с сегодняшним временем; остальные привычки — на свой следующий день.

**Синхронизация в обе стороны.** При каждом чтении файла приложение берёт из строк задач метки пула и секций (секцию с незнакомой меткой создаёт), а из строк привычек — их сегодняшнее время и список убранных Not today. Что убрано, сравнивается с тем, что это устройство видело в последний раз (`day-look.json` в App Group): если отличается, файл изменили руками или на другом устройстве, и приложение принимает это. Пока изменение не забрано, зеркало его не перезаписывает.

Рутины: свойство лежит в привычке (`options.timeOfDay` в JSON, `🌅` на строке — только для чтения глазами), порядок внутри рутины — в настройках приложения (`habits.morningRoutine`, `eveningRoutine`). Червяки (Select → Worm) и секция, в которую перетащена привычка, — на один день, в приложении.

## Что упростилось

- Зависимостей между задачами и от событий больше нет: цепочки, блокировки, пикеры связей и проверка циклов удалены из приложения.
- Нет `due` с часовым поясом внутри, нет `date_modified`, YAML, по файлу на задачу.
- Нет экрана конфликтов iCloud для задач: каждая запись читает файл заново и меняет только свою строку, так что побеждает последняя запись, а чужие строки не страдают. Если два устройства правят файл без сети одновременно, iCloud оставит одну версию, и приложение подхватит именно её.

## Как устроено в коде

Домен и экраны не знают о формате: они говорят с протоколом `TaskStore` (`Data/Store/TaskStore.swift`).

| Файл | Что делает |
|---|---|
| `Data/TaskFile/TaskFileFormat.swift` | конфиг `task-file.json` |
| `Data/TaskFile/TaskEntry.swift` | одна строка ⇄ структура |
| `Data/TaskFile/TaskDocument.swift` | весь файл ⇄ разделы, дерево строк; чужое сохраняется |
| `Data/TaskFile/TaskDocument+Today.swift` | разовый переход `## Today` старого файла в метки |
| `Domain/Day/TodayPool.swift` | правило пула: что ставит смена дня, что делает правка даты |
| `Domain/Day/Sections/PoolSectionTag.swift` | секция ⇄ метка `#section_…` |
| `Data/TaskFile/TaskEntry+Item.swift` | строка ⇄ `TaskItem`, раздел по статусу |
| `Data/TaskFile/HabitFile.swift` | JSON привычки, отметки как строки в Done |
| `Data/TaskFile/RepeatTag.swift` | правило повтора одним словом для `🔁` |
| `Data/TaskFile/TaskFileStore+Repeats.swift` | открытая строка привычки, её следующий день и просрочка |
| `Data/TaskFile/TaskFileStore*.swift` | actor-хранилище: чтение, смена дня, запись, корзина, зеркало, импорт |
| `Domain/Day/Sections/DayLook.swift` | что строки привычек говорят о сегодня: время и убранные |

`DayMirroring.mirror` зовёт `DerivedStatePublisher` после каждого изменения, `changedLook` — `SyncService` при каждом чтении. Запись атомарная, через `NSFileCoordinator`, и проверяется чтением обратно. Файл, который iCloud ещё не скачал, не считается отсутствующим: приложение ждёт его и не перезапишет пустым.

## Импорт из TaskNotes

Settings → Tasks → «From TaskNotes» → выбрать папку `TaskNotes`. Переносятся задачи, привычки с историей и папка Done. Папка `TaskNotes` только читается; задачи с уже существующими именами пропускаются, поэтому импорт можно повторить. Код адаптера TaskNotes (`Data/TaskNotes`) оставлен только для этого.
