# SuperPooper Open Line

Плагин Obsidian, который открывает `Tasks.md` на строке задачи и подсвечивает её. Нужен действию Open Obsidian: снаружи Obsidian номер строки передать нельзя.

Папка `superpooper-open-line` копируется в `.obsidian/plugins/` хранилища, плагин включается в Settings → Community plugins. Без него ссылка приложения не откроет файл.
